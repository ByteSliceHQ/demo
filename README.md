# Demo – Todo app

A dependency-free todo app (HTML, CSS, vanilla JS).

Features: add, toggle, edit (Edit button or double-click; Enter saves, Esc cancels), delete, filter (all/active/completed), items-left count, clear completed, and persistence in `localStorage`.

## Run

```
python3 -m http.server 8000 --bind 0.0.0.0
```

Then open http://localhost:8000. (Opening `index.html` directly also works.)
